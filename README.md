# Python-guessing-game
A number guessing game made with Python to practise programming fundamentals and problem-solving.

Features

- Multiple difficulty levels
- Random number generation
- User input and conditional logic
- Loops and dictionaries
- Replay functionality

Technologies Used

- Python 3

How to Run

1. Make sure Python 3 is installed.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Run:
   python guessing_game.py
   
   If that doesn't work on your system, try "python3 guessing_game.py".

What I Learned
This project helped me practise variables, loops, conditionals, dictionaries, functions, and organizing Python code.
